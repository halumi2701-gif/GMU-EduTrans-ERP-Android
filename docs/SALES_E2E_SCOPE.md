# Sales v6.3 End-to-End Production Scope

A release is considered end-to-end only when the following business chain is operational and auditable:

Join Sales -> Pending -> Owner review -> Provision -> Forced password change -> Active Sales -> Lead -> Qualification -> Follow-up/Visit -> Quotation -> SENT -> Customer decision -> Booking -> DP invoice -> Payment verification -> WON -> Handover Ops -> Trip lifecycle -> Completed -> Feedback/Testimonial -> Repeat opportunity -> Paid-pax attribution -> Commission visibility -> Sales report/ERP visibility.

Production checks must also preserve Sales privacy boundaries: no HPP, internal RAB, company profit, bank/cash balances, other staff payroll, or internal margin data may be exposed to the Sales role.
